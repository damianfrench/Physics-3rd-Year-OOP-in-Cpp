# OOP_module
assignments from the OOP in C++ module

## Assignment 1 - The Bohr Atom
Building a script to use the Bohr model to determine the energy of a photon for an electron transitioning between two energy levels for a specific atomic number.

## Assignment 2 - Course Marks Data
Building a script to take in data from a file of specific style containing information about a persons grades in their Physics degree at the University of Manchester, parse it for data and then return different features of the data dependant on the users request.
